Cube radar: follow the arrow

The in-game waypoint arrow points to your marker and counts down the distance. In this preview it reads 45 m.

  • Find a Hidden Cube spot on a tracker map.
  • Place a waypoint on that spot.
  • Fly toward the arrow until the distance reaches zero.
  • Open the HUD edit mode to resize the arrow; it shows here at 100%.

View-distance preview

What this config changes
  • View distance: Raises view-distance and level-of-detail/culling values for terrain, static meshes, foliage and grass, so more scenery may remain visible farther away.
  • Textures: Requests a 4096 MB texture-streaming pool, limited by available VRAM, zero mip bias and up to 16x anisotropic filtering where supported.
  • DLSS and anti-aliasing: Enables NVIDIA NGX/DLSS-related settings and selects temporal anti-aliasing. Actual support depends on the game, GPU and driver.
  • Performance note: Rendering more distant detail may increase GPU/VRAM use or affect performance. Some settings may be ignored or changed by game updates.

Restore your original settings

To undo these changes, clear Read-only on the modified file, replace it in the AION 2 config folder with the original backup you saved, then restart the game. If you do not have a backup, recover the original from your own saved copy; deleting the modified file alone may not restore it.

Installation guide

  1. 1

    Download and back up

    Download the new Engine.ini. Before replacing anything, make a copy of your current file so you can restore it later.

  2. 2

    Open the configuration folder

    Copy this folder path into File Explorer, then locate Engine.ini.

  3. 3

    Replace the existing file

    Move the downloaded file into the folder. When Windows asks, confirm that you want to replace the existing file.

  4. 4

    Set the file to read-only

    Right-click Engine.ini, choose Properties, check Read-only, then click Apply and OK. Clear this checkbox before replacing or restoring the file.
