# Aion 2 Legion Hub

Static site for the Aion 2 quality-of-life guide and its downloads.

## GitHub Pages

The site is configured to deploy automatically from the `main` branch with GitHub Actions. After pushing the project to `xFantooo/Aion2-Tool-Kit`, enable Pages in the repository settings and select **GitHub Actions** as the build and deployment source.

The expected site URL is <https://xFantooo.github.io/Aion2-Tool-Kit/>.

The page and assets are served from the repository root, so media and the `Engine.ini` download work at the project Pages URL.
